MindMate — Personalized AI Wellness Agent

Built during a 3-month Generative AI internship at DigiDARA Technologies: a personalized mental-health AI combining RAG pipelines, Pinecone vector memory, and agentic workflows for empathetic, context-aware support.

Role
Generative AI Intern — sole developer
Timeline
Jul 2025 (3-month internship)
Stack
Python · LangChain · HuggingFace · Pinecone · MongoDB · RAG
Links
GitHub — to be added

TL;DR

  • Personalized mental-health AI agent using all-MiniLM-L6-v2 embeddings + Pinecone for persistent user memory across sessions.
  • Agentic workflows for mood tracking, guided relaxation, and wellness prompts via prompt engineering and retrieval-based reasoning.
  • MongoDB stores session history and mood data; responses are contextually grounded — not generic chatbot replies.

Problem

Generic chatbots for mental wellness provide stateless, one-size-fits-all responses. Without session memory or retrieval of a user's history, they cannot build on previous conversations — every session starts from scratch, which is fundamentally unsuitable for a support context where continuity and empathy are essential.

Approach

MindMate uses all-MiniLM-L6-v2 embeddings (via HuggingFace) to encode user messages and prior session summaries into Pinecone — enabling semantic retrieval of relevant past interactions for every new message.

The agent routes messages to specialised workflows: mood tracking, guided relaxation, and wellness prompts. Each workflow retrieves relevant history from Pinecone and constructs a grounded, empathetic prompt. MongoDB stores raw session transcripts and mood-related metadata for auditability.

Outcome

MindMate was developed as the capstone project of the DigiDARA internship, demonstrating practical LLM application in a healthcare context. The agent maintained conversation continuity across multiple sessions — something stateless chatbots cannot achieve.

What I learned

  • Vector memory (Pinecone) fundamentally changes the user experience compared to in-context window history — session persistence across days is architecturally different from long-context prompting.
  • Agentic intent routing (mood vs. relaxation vs. wellness) required careful workflow design to avoid mis-classification on ambiguous inputs.
  • Healthcare AI requires explicit scope constraints — the agent was designed to redirect clinical concerns to professional resources, not replace them.
