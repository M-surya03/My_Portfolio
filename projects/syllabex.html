Syllabex — Syllabus-Grounded Learning Assistant

A controlled RAG system that ensures every AI-generated answer in an academic setting aligns with institution-approved syllabus content — solving the AI hallucination problem in education without banning AI entirely.

Role
Sole developer
Timeline
2026
Stack
Python · LLMs · RAG · Vector DB
Links
GitHub — to be added

TL;DR

  • Faculty upload textbooks and answer keys; content is embedded into a RAG pipeline — no unapproved content reaches students.
  • Students receive consistent, evaluation-friendly answers aligned with institutional answer keys.
  • Eliminates both extremes: rigid AI bans and unpredictable open-AI usage in academic contexts.

Problem

Students increasingly rely on general AI tools like ChatGPT for academic study. The problem: these tools produce confident, non-syllabus answers — contradicting institution-approved content, causing evaluation mismatches, and creating academic integrity issues that educators cannot reliably detect.

Institutions faced a false binary: ban AI entirely (removing a learning tool) or allow open AI use (accepting unpredictable, non-standard answers that undermine fair evaluation).

Constraints

  • Answers must be traceable exclusively to faculty-uploaded documents.
  • System must be operable by non-technical faculty (simple upload interface).
  • Must be evaluation-consistent: all students get structurally equivalent answers for the same question.

Approach

Faculty upload course materials (PDFs, DOCX files) through a simple admin interface. Documents are chunked, embedded, and stored in a vector database scoped to the specific course.

When a student queries the system, retrieval is bounded to that course's vector index — the LLM never has access to general internet knowledge for content outside the uploaded corpus. Answers are generated from retrieved syllabus passages and formatted to match evaluation-expected structure.

Outcome

Syllabex demonstrated consistent, syllabus-aligned answers across all test queries — no factually contradictory content, no information outside the uploaded corpus.

Qualitatively: the strict retrieval boundary eliminated the category of "correct-but-off-syllabus" answers that cause evaluation mismatch.

What I learned

  • RAG retrieval boundary (course-scoped index) is architecturally simpler and more reliable than prompt-based restrictions.
  • Chunking strategy matters significantly: semantic chunking by section outperformed fixed-token chunking for academic text.
